# SpendPact

*Autonomous spending. Human rules.*

SpendPact is a payment-policy firewall for AI agents on NEAR. An agent requests payments from a NEAR vault contract, the contract enforces spending limits on-chain, and anything above the auto limit needs the owner's wallet-signed approval of the exact payment.

**Status: pre-hackathon planning. There is no code yet.** Implementation starts during NEAR HACKATHON 2026 (November 1-14, 2026 UTC). Nothing in this repo is evidence of implemented security.
